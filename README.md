# Aşk-ı Memnu — 2D Stealth Game

Unity ile geliştirilen 2D gizlilik oyunu.

## Nasıl çalıştırılır

1. Unity Hub ile projeyi açın.
2. `Assets/Scenes/MainMenu.unity` sahnesini açın.
3. Play'e basın.

## Bölümler

- **MainMenu** — Ana menü
- **SampleScene** — Bölüm 1
- **Level2** — Bölüm 2
- **Level3** — Bölüm 3

## Kontroller

- **WASD** — Hareket
- **ESC** — Duraklat

## Mekanikler

- Bihter'in dairesi içinde durdukça parfüm barı dolar.
- Bar tamamen dolunca bölüm tamamlanır.
- Daire içindeyken bir NPC tarafından görülürsen oyun biter.
